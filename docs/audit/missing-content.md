# 内容缺失分析（missing-content）

- 勘察日期：2026-09-27
- 范围：对照「零基础 → 本科实习实操水平」目标与《计划》要求的教学闭环，盘点结构性缺失。

## 1. 教学闭环层缺失（最普遍）

1. **练习层几乎不存在**：1803 篇中带独立练习栏位的约 18 篇（1%）。缺：预测题（先猜输出再运行）、修改实验（改代码观察变化）、修 Bug 题（给错误代码与报错）、挑战题（脱离示例自己实现）。javascript 030-060 系列的「练习：修 Bug」是全库唯一成体系的样例。
2. **运行验证缺失**：批量文档的代码极少给出预期输出，从不要求读者执行并核对结果——「学生有没有真正运行代码」这一环全库缺位。
3. **调试教学只在 001-start 存在**：其他模块的「常见陷阱」是散文罗列，没有「遇到这个报错，读哪几行，怎么改」的实录格式。
4. **官方文档衔接缺失**：抽样 59 篇仅约 10 篇引用官方文档。各模块 module.json 的 officialDocs 字段其实已经维护了官方链接，但没有进入文档正文引导读者去读。
5. **「何时不用」缺失**：小文档普遍没有使用边界讨论；仅 redis/sql 大文件的选型章覆盖。

## 2. 项目与作品集层缺失

1. 项目散落在各模块（python/970 爬虫与数据分析、mysql/870 数据库设计等），没有结构化的「阶段项目路线」（Level 0 极小实验 → Level 7 综合项目的分层在《计划》中明确要求）。
2. 没有作品集/毕业项目体系：roadmap 的 11 条路线有「检验项目」栏目但纯叙述、无机器可读元数据、无项目难度分级与验收标准。
3. 缺「高提示 → 低提示 → 无提示」的提示梯度设计：现有项目篇直接给完整代码，训练的是照抄而非独立完成。

## 3. 就业能力层缺失

1. **游戏开发就业路线缺失**：仓库有 5 个游戏模块（godot/gdscript/renpy/gode/konado）但 roadmap 的 11 条路线无一覆盖。
2. **AI 协作开发环节缺失**：roadmap 总览声称「超过一半的技术岗位要求 AI 协作开发能力」，但没有对应模块或路线（AI 内容散落在 python/990/1010/1020）。
3. **工具链教学链不完整**：终端、Git、包管理器、调试器、测试、格式化、Lint、日志、环境变量、依赖管理、构建、部署——分散在各模块且未串成「真实开发环境」递进线（001-start/030 与 shell 模块部分覆盖）。
4. nestjs 缺认证/JWT 专篇（对应岗位高频要求）。
5. python 缺 argon2id/密码存储现代方案篇（java/go/kotlin 有，主线语言反而没有）。

## 4. 结构衔接层缺失

1. **start 与语言模块无直接交接**：001-start 全部出站链接只指向 roadmap/git/markdown/cybersecurity，没有任何一篇直链 `python/010-WhatIsPython` 或 `javascript/010-WhatIsJavaScript`；反向也无回指。第一周体验与主线课程之间仅靠 roadmap 间接转接。
2. **roadmap 模块计数过时**：自称 36 个模块，实际 43。
3. **5 个游戏模块路径未注册到 web 端**（见 curriculum-audit.md 第 5 节）。
4. **环境搭建四处重复**（001-start/030、python/020/030/040）——不是缺内容，是缺分工声明：谁负责通用环境、谁负责语言专属。

## 5. 各模块实操化缺口（需要补「动手」的模块清单）

抽样确认完全零练习零动手的模块：003-git（42 篇）、017-mysql 批量部分、021-cs-fundamentals（63 篇）、028-software-testing（48 篇）、032-python（除 010 外）。其中 cs-fundamentals 与 software-testing 需要特殊处理：前者适合改为「实验验证型」（用命令验证操作系统/网络原理），后者适合改为「对真实项目写测试」的实操型，而不是维持纯理论罗列。

## 6. 补缺优先级

1. 练习层与运行验证（贯穿全部重写批次，不是独立补丁）；
2. start 与 python/javascript 的双向直接链接（一天工作量，体验收益最大）；
3. roadmap 游戏路线与 AI 环节；
4. 项目层结构化（先给 roadmap 检验项目补机器可读元数据）；
5. mysql/760 密码哈希、nestjs 认证、argon2id 三个安全/工程补丁；
6. 环境搭建四处分工重整。
