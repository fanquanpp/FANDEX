## 学习目标

前面各篇给了"学什么"，本篇给"怎么落成每天的动作"。读完你将拥有一份可直接填写的个人计划表：周节奏模板、月度检查点、里程碑项目清单、弃坑预警与恢复机制。它不挑路线——前端、后端、测试皆可套用。

## 前置知识

已选定路线（[路线总览](/roadmap/010-RoadmapOverview)），知道自己的主线模块与三阶段划分。

## 第一步：确定你的时间预算

诚实填写（这决定用哪个版本）：

| 情形 | 每周有效学习时间 | 采用版本 |
| --- | --- | --- |
| 全职学习/在校 | 30 小时以上 | 标准版（12 个月） |
| 在职/课业重 | 10 到 15 小时 | 慢速版（周期 x1.5，约 18 个月） |
| 极度碎片 | 5 小时以下 | 极简版（只做主线 + 项目驱动） |

"有效学习时间"指动手敲代码或做题的时间，看视频看文档打对折计算。

## 周节奏模板（可打印）

标准版的一周是这样循环的：

| 时段 | 内容 | 说明 |
| --- | --- | --- |
| 周一至周五，每天 1 到 2 块 | 主线推进 | 学路线计划中当前文档，完成动手环节与检验清单 |
| 每天 20 到 30 分钟 | 算法/手写支线 | 当前阶段对应题量（阶段 1 每周 3 题，阶段 2 起每天 1 题） |
| 周六上午，2 到 3 小时 | 项目时间 | 只推进当前里程碑项目，不开新坑 |
| 周六下午，1 小时 | 周复盘 | 填写复盘表（见下），决定下周计划 |
| 周日 | 休息或自由探索 | 真休息。可持续比强度重要 |

慢速版：主线减半、项目时间挪到双周，其余同构。极简版：砍掉支线与复盘表，只保留"每天 30 分钟主线 + 每周一次 2 小时项目"。

## 月度检查点（12 个格子里放什么）

每月最后一周回答三个问题，写成五行笔记：

```text
1. 本月学到的最重要的一个概念是什么？（一句话）
2. 里程碑推进了多少？离下个里程碑还差什么？
3. 下月只保留哪三件事？（其余全部砍掉）
```

里程碑对照表（以标准版为例，按你选定的路线文档校正具体项目）：

| 月份 | 里程碑 |
| --- | --- |
| 第 1 月 | 环境就绪 + 主线模块前 25% + git 仓库建成 |
| 第 2 月 | 主线模块 50% + 第一个小项目可演示 |
| 第 3 月 | 阶段 1 完成：能独立写 200 行程序 + 阶段验收项目 |
| 第 4 月 | 方向框架/数据库开工 + 算法累计 30 题 |
| 第 5 月 | 主框架项目主体完成 |
| 第 6 月 | 阶段 2 完成：项目部署上线（有公网 URL） |
| 第 7-8 月 | 深度课题（性能/安全/运维按路线）+ 主项目开工 |
| 第 9-10 月 | 作品集主项目完成：上线 + README + 数据 |
| 第 11 月 | 复习冲刺：八股/原理自测 + 简历定稿 |
| 第 12 月 | 模拟面试 5 轮 + 投递或进阶计划 |

## 每日最小闭环

无论多忙，每天保住这个 30 分钟最小闭环（它保证"学习状态不断电"）：

```text
5 分钟   回顾昨天笔记（主动回忆：先不翻，想）
20 分钟  推进当前文档的一个小节或一道题
5 分钟   记一行"今日收获/今日坑"
```

## 复盘表与防弃坑机制

**周复盘表**（每周一次，五行）：

```text
本周完成：        （对照上周计划）
未完成与原因：    （诚实记录，不找借口只找模式）
本周最大的坑：    （一句话）
下周三件事：      （具体到文档/题目编号）
状态自评：        状态好/一般/疲惫
```

**弃坑预警信号**（出现两条以上启动干预）：

1. 连续 3 天没碰最小闭环；
2. 周复盘连续两周"未完成"超过一半；
3. 开始频繁浏览"转行还来得及吗"类内容；
4. 对里程碑产生"反正也完不成"的念头。

**干预动作**（按序尝试）：

1. 砍计划：本周目标砍半，先赢回"完成感"；
2. 降难度：回到上一个"检验清单全过"的位置，做变体练习；
3. 换输入：卡住的文档换一个角度（做项目卡了就读文档，读文档卡了就做项目）；
4. 找同伴：公开进度（GitHub 提交记录本身就是），或找学习搭子互相检查周复盘；
5. 休整一周：彻底休息，日历上写好重启日期——计划中断不可怕，无重启日期的中断才致命。

## 落地动作：今天就做

1. 复制本文的周节奏与里程碑表到一个新 Markdown 文件，命名 `my-plan.md`，放进你的代码仓库（顺便完成 git 第一次提交）；
2. 填好时间预算版本与路线对应的里程碑项目名；
3. 设置三个日历提醒：每日最小闭环、周六复盘、月末检查；
4. 在你的 `my-plan.md` 里写下第一周的三件事（具体到文档编号）。

## 常见困惑

**"计划总被打断（加班/考试/生活），怎么办？"**——计划的意义是"中断后知道回到哪"，不是"完美执行"。任何中断后：回到本文弃坑干预第 2 步（回到上个检验点）重启，永远不要从头再来。

**"跟着视频课程学和这份计划冲突吗？"**——不冲突。把视频课当主线文档的替代输入即可，检验清单与里程碑照旧。唯一要求：视频里的代码必须亲手敲进你自己的仓库。

**"12 个月后没达到求职水平怎么办？"**——先做差距分析：是里程碑项目没做完（补项目），还是八股自测不过（补复习），还是算法量不够（加量）。计划是仪表盘，按数据补短板，而不是推倒重来。

## 检验清单

- `my-plan.md` 已建好并完成第一次提交；
- 时间预算版本已选定，里程碑已按路线校正；
- 三个日历提醒已设置；
- 第一周三件事已写明，具体到文档编号。
