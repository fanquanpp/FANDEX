## 编程到底是什么

程序就是**一份写给计算机的、精确到每一步的操作清单**。编程就是把人类脑子里的想法，翻译成计算机能逐条执行的清单。

一个生活中的对照：你让新来的实习生"整理一下文档"，他会按自己的理解去做；但你必须给计算机写成"遍历文件夹，筛选扩展名为 .txt 的文件，按修改时间排序，移动到归档目录"——它才会执行。**计算机不会猜，所以编程训练的第一能力是把想法拆解为无歧义的步骤。**

```mermaid
flowchart LR
    A[想解决的问题] --> B[拆解为明确步骤]
    B --> C[用编程语言写成代码]
    C --> D[工具翻译成机器指令]
    D --> E[计算机执行并给出结果]
```

## 编程语言的全景图

世界上有上百种编程语言，常用的不到二十种。按用途粗分：

| 方向 | 代表语言 | 典型产出 |
| --- | --- | --- |
| 网页前端 | JavaScript、TypeScript | 浏览器里的交互页面 |
| 服务端与全栈 | Python、Java、Go、Node.js | 网站后台、接口服务 |
| 移动应用 | Kotlin、Swift | 手机 App |
| 系统与高性能 | C、C++、Rust | 操作系统、游戏引擎 |
| 数据与脚本 | SQL、Shell | 数据查询、自动化任务 |

它们共享几乎相同的思维内核：**变量存数据、条件做判断、循环做重复、函数做复用。** 学通一门语言后，第二门语言通常只需几周——这正是本仓库把语言模块都按相似路径组织的原因。

## 第一门语言怎么选

给零基础读者的三条务实建议：

1. **跟随目标选**：想做网页选 JavaScript（浏览器只认它）；想做数据分析与自动化选 Python；面向求职的企业级开发选 Java 或 Go。
2. **不要在选语言上消耗超过一天**：第一门语言教会你的编程思维可以迁移，选哪个都不亏。
3. **跟着主线走**：本仓库推荐主路径为 `getting-started → html5 → css → javascript → typescript → python/java → 数据库 → 框架与工程`，每一步都有前置依赖标注，跟着顺序学即可。

## 动手环节：读一段程序

不用理解每个细节，感受一下代码长什么样。下面是 JavaScript 写的"从 1 加到 100"：

```javascript
let total = 0;          // 准备一个存结果的变量
for (let i = 1; i <= 100; i++) {  // 从 1 循环到 100
  total = total + i;    // 把当前数累加进结果
}
console.log(total);     // 打印结果：5050
```

三行核心逻辑对应人类思维的三步：准备账本、逐个数、记录合计。编程没有魔法，只有拆解。

## 常见困惑

**"数学不好能学编程吗？"**——常规软件开发用到的数学不超过初中水平：加减乘除、取余数、简单逻辑判断。算法与图形学方向才需要更多数学。

**"英语不好能学编程吗？"**——编程语言的关键词只有几十个（如 `if`、`for`、`return`），见到就认识；报错信息可以借助翻译工具读懂，且本仓库的文档会用中文把每个概念讲透。

**"多久能学会？"**——按本仓库主线，每天投入两小时，四周可以独立写出小程序；三个月能做出完整的网页项目。学习曲线是平缓上升的，关键是连续不断档。
